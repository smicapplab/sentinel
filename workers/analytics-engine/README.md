# Sentinel Analytics Engine (Python)

Data science and statistical modeling worker for Project Sentinel.

## Key Modules
- **`src/nbi_engine.py`**: Next-Best-Item (NBI) Market Basket Analysis via Association Rules.
- **`src/fraud_radar.py`**: Discount & Void Z-Score Anomaly Detection with demographic peer clustering.

## Setup & Execution
```bash
pip install -r requirements.txt
python main.py all <franchise_id>
```
